# CLA signatures

Signer records for kody-hq/kody-celld. The `📝 Record CLA after merge` job in
`.github/workflows/cla.yml` on `main` commits new individual signers to
`cla-signers.json` here, and the `✍️ CLA` check reads it. Maintainers edit the
same file for Entity CLA signers and the allowlist. See
`docs/contributing/inbound-contributions.md` on `main`.
